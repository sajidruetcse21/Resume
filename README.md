# Sajid Resume (LaTeX)

This repository contains the LaTeX source code for the resume of Md. Sajedul Islam.

## Project Structure
- **Sajid_Resume.tex** — Main LaTeX source file for the resume
- **Sajid_Resume.pdf** — Compiled PDF output (not tracked by git)
- **.gitignore** — Excludes LaTeX build and temporary files, and VS Code settings

## Features
- Clean, professional resume template written in LaTeX
- Easy to edit and customize
- Modern sections: Education, Projects, Skills, Achievements, Certifications, and more
- Hyperlinks and icons for contact and portfolio

## How to Build the Resume
1. **Install a LaTeX distribution**
	- Windows: [MiKTeX](https://miktex.org/download) or [TeX Live](https://www.tug.org/texlive/)
2. **(Recommended) Install VS Code Extension**
	- [LaTeX Workshop](https://marketplace.visualstudio.com/items?itemName=James-Yu.latex-workshop)
3. **Open the project folder in VS Code**
4. **Edit the file**: Open `Sajid_Resume.tex` and make your changes
5. **Build/Compile**
	- Save the file or use the build command (usually `Ctrl+Alt+B`)
	- The PDF will be generated as `Sajid_Resume.pdf` in the same folder

## Usage Instructions
- To update your information, simply edit the relevant sections in `Sajid_Resume.tex`
- To add new projects, achievements, or skills, follow the structure of the existing entries
- Do not edit the PDF directly; always edit the `.tex` file and recompile
- If you use Overleaf, you can upload the `.tex` file and compile online
